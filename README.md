# Sales and Customer Insights Analysis
This project analyzes retail transaction data from the Istanbul Shopping Dataset using SQL and Power BI. It explores sales trends, customer behavior, and payment patterns through an interactive dashboard, providing clear business insights for data driven decision making.

**Overview**
This project analyzes retail transaction data to uncover key business insights related to sales performance and customer behavior. The dashboard was built using SQL and Power BI.

**Dataset**
The project uses the Istanbul Shopping Dataset, which contains transaction-level data from multiple shopping malls between 2021 and 2023.

Key features of the dataset:
- Customer details (age, gender)
- Transaction data (invoice, quantity, price)
- Product categories
- Payment methods
- Shopping mall locations

**Objectives**
- Analyze overall sales performance
- Identify top-performing product categories and malls
- Understand customer demographics and spending behavior
- Evaluate payment method preferences
- Track monthly revenue trends

**Tools Used**
- SQL (MySQL) – Data analysis
- Power BI – Dashboard and visualization

**Dashboard Features**

**Sales Overview**
- Total Revenue, Orders, Customers, AOV
- Monthly Revenue Trend
- Revenue by Category
- Revenue by Shopping Mall
- Revenue by Payment Method
- Revenue by Age Group
- Revenue by Gender

**Key Insights**
- Certain categories contribute the majority of revenue
- Sales show monthly variations indicating possible seasonality
- Credit card is the most preferred payment method
- Customers aged 25–40 contribute the highest revenue
- A small group of customers drives a large portion of total sales

 **Conclusion**
This project demonstrates how SQL and Power BI can be used together to transform raw data into meaningful business insights and interactive dashboards.
